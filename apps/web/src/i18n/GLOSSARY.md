# Georgian glossary

How the Developer22 website writes Georgian (`dictionaries/ka.ts`, and the `ka` side of
translatable database text). Follow it for every new Georgian string; when a native speaker
corrects something, add the lesson here. Tone rules are shared with Shelby's glossary.

## Tone

- **Formal, always: თქვენ.** აირჩიეთ, დააჭირეთ, დაგვიკავშირდით. Never the informal შენ form.
- Prefer how Georgian developers' sites actually say it over a word-for-word translation of
  the English. If a sentence reads like a translation, rewrite it.
- Errors: **დაფიქსირდა შეცდომა.** Retry hint: **სცადეთ თავიდან.** / **სცადეთ ცოტა ხანში.**
